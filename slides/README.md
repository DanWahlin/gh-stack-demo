# Slide deck source

Dan's PowerPoint is the source of truth. The current foundation is stored identically in:

- `github-stacked-prs.pptx` — working/final deck
- `github-stacked-prs-animated-base.pptx` — protected foundation for future edits

The deck currently contains:

1. Getting Started with GitHub Stacked PRs
2. The dilemma: giant PR versus serial small PRs
3. The solution: dependent development with focused reviews
4. The workflow: create, submit, review, and merge

The content slides include Dan's PowerPoint animations. Future changes must start from `github-stacked-prs-animated-base.pptx` and use targeted OOXML edits so those animations are preserved. Do not regenerate the full deck from the HTML sources.

Every slide includes a clickable `gh.io/stacks` badge and GitHub's Invertocat mark.
