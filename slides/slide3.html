THE WORKFLOW

From branches to one visible stack

The CLI handles branch order, pull-request bases, rebases, and merging.

1

Create layers

Start the stack, then add one branch per reviewable concern.

gh stack init
gh stack add

→

2

Submit once

Push branches, create correctly based PRs, and link the stack.

gh stack submit

→

3

Review + land

Review focused diffs, update dependent layers, then land all or part of the stack.

gh stack rebase
gh stack merge

The result: smaller reviews without serial development.
