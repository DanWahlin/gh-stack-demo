A REAL STACK, START TO FINISH

Create three stacked pull requests

Run this inside a clean repository with an authenticated GitHub CLI and a configured remote.

task-api — bash

# Install once

$ gh extension install github/gh-stack

# Layer 1: model

$ gh stack init feature/task-model

# edit src/model.js

$ git add src/model.js

$ git commit -m "feat: add task model"

# Layer 2: API

$ gh stack add feature/task-api

# edit src/api.js

$ git add src/api.js

$ git commit -m "feat: add task API"

# Layer 3: tests

$ gh stack add test/task-api

# edit test/api.test.js

$ git add test/api.test.js

$ git commit -m "test: cover task API"

# Inspect, then create all three PRs

$ gh stack view

$ gh stack submit

# submit pushes, opens PRs, and links the stack

# Later: update and land the stack

$ gh stack sync

$ gh stack merge

Key idea: commit each focused change before adding the next layer.

Interactive submit lets you review titles, descriptions, and draft state.
